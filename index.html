はじめに

出納簿 bot は、部のお金の出入りを Discord から記録する bot です。記録は会計の人の承認を経て、Google スプレッドシートの出納簿に残ります。部員がスプレッドシートを直接さわる必要はありません。

最初に一度だけ: 登録する

  1. メッセージの入力欄に /register と打ち、候補から「登録」を選ぶ
  2. 「学籍番号」に自分の学籍番号を入れて送信する（「氏名」は省略できます）

登録しないと、収入・支出の記録や立替の申請はできません。間違えたときは、もう一度 /register を実行すれば上書きされます。差し戻しの通知メールは学籍番号の学生メールに届くので、正しく入れてください。

コマンドの出し方

  • 入力欄に / を打つと、コマンドの一覧が出ます。Discord の表示言語が日本語なら、日本語の名前（例: /出納）でも探せます。このマニュアルでは /entry（出納）のように両方を書きます。
  • 迷ったら /help（ヘルプ）を実行します。自分が使えるコマンドだけが表示されます。/help command:entry のように指定すると、そのコマンドの入力例と注意点が出ます。
  • /help などの応答は、自分にだけ見えます。

収入・支出を記録する: /entry（出納）

部のお金を払ったとき・受け取ったときは、/entry で記録します。自分のお金で立て替えたときは、次の節の /advance を使います。

項目入力書くこと
区分必須収入か支出か
科目必須お金の分類。候補の一覧から選ぶ（例: 備品・大会参加費・部費）
金額必須円単位の整数（例: 3980）
摘要必須具体的な中身。自由に書く（例: 早押しボタン 2 個）。200 文字まで
日付任意お金が動いた日。2026-11-20・11/20・今日・昨日 のどれかで入力。省略すると今日
領収書原則必須レシート・領収書の写真か PDF（JPEG / PNG / HEIC / PDF）。収入は振込通知・売上集計表など
領収書なしの理由領収書がないとき必須領収書を添付できない理由
資金区分任意使い道が決まっているお金（支援金など）のときだけ選ぶ

科目と摘要の違い

科目はお金の分類で、一覧から選ぶだけです。摘要は具体的に何を買ったか・何の収入かを、自分の言葉で書きます。

やったこと区分科目摘要
早押しボタンを買った支出備品早押しボタン 2 個
問題集を買った支出書籍・問題集問題集 3 冊
大会の参加費を主催者に払った支出大会参加費○○大会 3 人分
大会の参加費を部員から集めた収入参加費徴収○○大会の参加費 3 人分
理大祭の売上を受け取った収入理大祭収入理大祭 1 日目の売上

合う科目がないときは「雑費」「雑収入」を選ぶか、会計に相談してください。科目の一覧は会計が管理しています。

入力例

/entry kind:支出 category:備品 amount:3980 memo:早押しボタン 2 個 receipt:(写真)

記録したあと

  • 送信すると「✅ 登録しました。会計チャンネルで承認を待っています。」と出て、会計チャンネルに承認依頼が投稿されます。
  • 会計ロールの人が承認すると、承認依頼の「状態」が「✅ 承認済み」に変わります。承認されたときの個別の通知はありません。
  • 一定額以上の記録は、別々の 2 人の承認が必要です。自分の記録を自分で承認することはできません。
  • 差し戻されたときは、「差し戻されたとき」の節を見てください。
  • 未来の日付と、会計が締めた月の日付は入力できません。

立て替えたお金を返してもらう: /advance（立替申請）

自分のお金で部のものを買ったら、/advance で返還を申請します。承認されたあと、会計が現金で返してくれます。

項目入力書くこと
科目必須お金の分類。支出の一覧から選ぶ（例: 書籍・問題集・備品）
金額必須立て替えた金額（円）
摘要必須買ったものの具体的な中身（例: 問題集 2 冊）
購入日任意買った日。省略すると今日
返還先任意お金を返す相手。省略すると自分。ほかの部員の分を代わりに申請するときに使う
領収書原則必須レシート・領収書の写真か PDF
領収書なしの理由領収書がないとき必須領収書を添付できない理由
 
/advance category:書籍・問題集 amount:1980 memo:問題集 receipt:(レシートの写真)

申請したあと

  1. 会計チャンネルに承認依頼が投稿され、会計ロールの人が承認します。
  2. 承認されただけでは、まだお金は戻っていません。会計から現金を受け取ってください。
  3. 会計が返還を記録すると、会計チャンネルで「立替金を返還しました」とメンションされます。この時点で出納簿に支出として記録されます。

返還は全額だけで、一部だけ返すことはできません。まだ返ってきていない立替金は、/advance-status（立替状況）で確かめられます（自分の分だけ表示されます）。

差し戻されたとき: /resubmit（再提出）

差し戻された記録や立替は、理由に合わせて直し、/resubmit で出し直します。新しく /entry し直す必要はありません。

通知の届き方

  • 会計チャンネルでメンションされます。「申請 01JD... が差し戻されました。理由: …」のように、ID と理由が書かれています。
  • 同じ内容が学生メールにも届きます。

直し方

  1. /resubmit を出し、「id」に差し戻された ID を入れる（候補に自分の差し戻されたものが出ます）
  2. 直したい項目だけを入れる（科目・金額・摘要・日付・領収書など）。入れなかった項目は元のままです
  3. 送信すると、もう一度承認待ちになります
/resubmit id:01JD... receipt:(撮り直した写真)

再提出できないもの

  • 部費の納入や逆仕訳から自動で登録された取引。会計が元の操作をやり直します。
  • 日付を別の年度（4 月始まり）に変える再提出。
  • 再提出の回数や期限に上限がある場合は、超えると「再提出は○回までです」などのエラーになります。そのときは会計に相談してください。

部費: /dues-status（部費状況）

部費は会計に渡すだけでよく、部員が bot で記録することはありません。会計が受け取ったことを記録します。

自分の納入状況は /dues-status で確かめられます。請求ごとに「未納」「納入済み」「免除」のどれかが表示され、自分の分だけが見えます。

払ったのに「未納」のままのときは、会計に伝えてください。会計の記録が差し戻された場合も、「未納」に戻ります。

会計ロールの人へ

会計ロールの人は、承認と、部費・立替・締めの記録を担当します。会計ロールの人も、最初に /register で登録しておいてください（/dues-pay と /reverse は登録が必要です）。

承認・差し戻し

  • 会計チャンネルの承認依頼にある「承認」「非承認（差し戻し）」ボタンを押します。先に押された操作で確定し、そのあとの操作は断られます。
  • 領収書は承認依頼の「開く」から確かめます。領収書がない申請は「⚠️ 領収書なし」と理由が目立つように表示されます。
  • 自分の申請は自分で承認できません。
  • 一定額以上の申請は、別々の 2 人が承認した時点で承認済みになります。1 人目が押すと「あと 1 人」と表示されます。
  • 差し戻すと理由の入力欄が開きます。理由は入力者へのメンションとメールにそのまま載るので、何を直せばよいかが分かるように書いてください。
  • 100 時間以上承認されていない申請は、会計チャンネルに一覧が出ます。

会計のコマンド

こんなときコマンド入力例
運用開始時・年度の初めに残高を入れる/opening-balance（期首残高）/opening-balance amount:52300
部費を請求する/dues-set（部費請求）/dues-set period:2026年度前期 amount:3000 due_date:2026-05-31
部費を受け取った/dues-pay（部費納入）/dues-pay member:@部員 dues:2026年度前期
部費を免除する/dues-exempt（部費免除）/dues-exempt member:@部員 dues:2026年度前期 reason:休部中
立替金を返した/advance-repay（立替返還）/advance-repay id:01JD...
承認済みの記録の誤りを直す/reverse（逆仕訳）/reverse id:01JD... reason:金額の入力誤り
月を締めて残高を確定する/close（月締め）/close month:2026-10
締めた月の月次報告を取り出す・作り直す/monthly（月次）/monthly month:2026-10
全員分の部費・立替を見る/dues-status・/advance-statusmember を省略すると全体が出る
  • /dues-set で member を省略すると、在籍中の部員全員に請求します。請求しただけでは出納簿に記録されません。
  • /dues-pay で納入を記録すると、科目「部費」の収入が承認待ちで登録されます。記録した人とは別の人が承認します。領収書は要りません。
  • /advance-repay は全額返還だけです。返還した日が取引日になり、立替者にメンションで知らせます。
  • /reverse は元の記録を消さず、同じ金額で反対向きの記録を足して打ち消します。正しい内容は改めて /entry で入れてください。
  • /close は承認待ちが残っていると締められません。月は運用開始月から順に締めます。締めた月の記録は変更できません。
  • 年度末の /year-close（年次締め）は、3 月まで締めてから実行します。

よくある質問・困ったとき

たいていのエラーは、メッセージに直し方が書いてあります。直してもう一度送信してください。

表示されたメッセージ・困りごとどうするか
「先に /register で学籍番号を登録してください」/register で登録してから、もう一度実行する
「科目「○○」は…の科目一覧にありません」科目は自分で打たず、候補から選ぶ。収入と支出で選べる科目が違うので、区分も確かめる
「領収書…を添付するか、添付できない理由を入力してください」領収書を添付する。なくしたときなどは「領収書なしの理由」に理由を書く
「領収書を…圧縮できませんでした」領収書だけが写るように撮り直す。PDF は 2MB 以下にする
「未来の日付…は入力できません」お金が動いた日を入れる。支払いの予定は、実際に払ってから記録する
「○月は締め済みのため…登録・変更できません」会計が締めた月の日付では入力できない。会計に相談する
「❌ 処理中にエラーが発生しました」時間をおいてもう一度試す。続くときは会計に連絡する
入力を間違えた（まだ承認待ち）会計に差し戻してもらい、/resubmit で直す
入力を間違えた（もう承認済み）会計に伝える。会計が /reverse で打ち消し、正しい内容を /entry で入れ直す
コマンドが候補に出ない部の Discord サーバーの中で / を打つ。DM では使えない。出なければ Discord を再起動する

ここにないことや、分かりにくいところは会計に聞いてください。
